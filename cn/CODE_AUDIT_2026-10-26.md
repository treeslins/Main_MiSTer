# Main_MiSTer 中文 OSD：旧版与 ZLabs 版源码审计

日期：2026-10-26。对象：旧版 `chinese-osd-prototype` / PR #1 与新版 `feature/mister-cn-zlabs-integration` / PR #3。以 GitHub 实际源码、固定 `misterfpga.cn` 字库、602 条中文翻译、GitHub Actions CI 为依据。

## 选择

长期选择 **新版 PR #3**：沿用旧版菜单翻译/8 行视口/滚动/图标机制，同时独立加载固定 ZLabs RoundPix 16px 字库并每天对官方上游尝试合并和构建。尚未经 MiSTer CRT/HDMI 真机测试，暂不应作为稳定版发布。

**旧版优势**：279,058 字节 Unifont 子集嵌入程序、无独立字体安装问题，适合做兼容性参考；新版优势是用户指定的固定 ZLabs 16px、更广覆盖、字库无需随每次上游编译重新生成。

旧版特有码位主要是注音符号及制表/换行等控制码位。新版的箭头 `←`、`→`、`上级目录`、`[目录]`、`代码：` 等代码额外使用的字符也已查验存在；`•`、`✓` 不在本字体中。

固定字体：314,376 字节，SHA-256 `cb8afcf32aabfc566ee0e39cd282c5d5a2c20049f2252dd26258696481c1a517`。它由分支 `cn/assets/misterfpga.cn` 原样复制，CI **不重新生成**。

## 此次已经修复

1. **箭头更新遗漏**：原 `OsdSetArrow()` 仅更新 `arrow`，未让 `zh_dirty` 失效；某些仅改箭头的状态变化可能不刷新中文显示。现已在箭头改变时置 `zh_dirty=true`。
2. **16/19 物理行残留**：原 `OsdClear()` 和中文信息面板仅清前 16×256 字节，`is_menu()` 则仍可能上传 19 条物理行。现改为全缓冲清理；中文模式上报第 16–18 行前还会清掉残留数据并标记脏行，保留标准 SPI 256 字节/行提交。
3. **GitHub 发布源码不一致**：以前预发布 Tag 以 `master` 为目标，但产物来自临时合并后的上游工作树；Tag 源码不等于实际二进制的源码。现保存 `upstream-merge.patch` 以及 SHA-256，Tag 目标改为构建的中文源码基点；需要检出基点并应用补丁，才能重建本次临时上游合并代码。仍需持续验证可复现性。

这些修正已通过 GitHub Actions 的 host 测试、字体检查和 ARM 交叉编译，并不代表实体 MiSTer 兼容性已证实。

## 尚待修复或真机检查（区别于已复现 Bug）

- **同名菜单切换时的陈旧行（条件性风险）**：`OsdSetTitle` 只有中文标题文本变化时才清空 `zh_page`。如果两个页面标题相同且没有经过 `OsdClear`，前一页没有被当前页面覆盖的条目可能残留。需要用真正菜单状态切换复现，避免盲目改为每次重绘都清空。
- **特殊显示参数未完整继承（源码已确认）**：中文分支提前返回 `OsdWriteOffset`，并未复刻所有的 `offset`、`usebg` 与传统滚动/背景组合。旧版特效、部分核心的 OSD、动画背景可能与英文版不一致。应先定位真实调用点并增加回归测试。
- **菜单空白间隔被压缩（已确认行为）**：`ZhPage::visible()` 排除空行，而官方原始菜单可能用空行分组。可能影响层次感和选中项附近的布局，属 UI 兼容性而非内存 Bug。
- **字体缺失后不能热加载（已确认行为）**：`load_once()` 首次失败后进程不再尝试读取字库，复制字体文件后需要重启 MiSTer。可以增加手动重试或初始化日志。
- **翻译匹配算法**：`ZhTranslate()` 对每个文本位置遍历 602 个条目并重复计算 `strlen`，可以预编译前缀字典/Trie 或缓存长度；需先跑 ARM 性能数据，避免无依据改写。
- **测试空白**：当前 CI 测试 8 行布局、UTF-8、反白、字体位序和 ARM 编译，仍缺少 SPI 数据模拟、OSD 真正启用/关闭及 19 行核心菜单的端到端测试。
- **GitHub 定时触发**：workflow 只有进入默认分支后才会按计划运行，PR #3 未合并时其绿色 PR CI 不等于每日定时功能已正式启用。
- **字体额外符号**：虽然 602 条中文词条无缺字，后续新增动态菜单、含注音的文件名与某些特殊符号仍可能回退缺字框。

## 真机测试优先顺序

1. 同时复制新 `MiSTer`、固定 `misterfpga.cn` 到 SD 根目录，先备份可启动版本；验证 `osd_language=1/0`。
2. 普通菜单 8 行视口、上下翻页、退出固定、标题侧栏、左右箭头刷新。
3. 文件浏览中短/长 UTF-8 文件名，滚动时重复进入文件夹，目录日期、ZIP 标记。
4. 16 行中文菜单与 19 行 `is_menu()` FPGA 视图之间来回切换，观察底部 3 行是否出现旧内容。
5. 提示框、帮助、旋转、HDMI/CRT、不同 FPGA 核心；观察背景图、图标、反白区域。
6. 移走字库验证英文退路；补回字库后重启重新显示中文。

**安全结论：** 原版与新版都不能因 GitHub CI 成功就宣称完成真机验收。仅在草稿 PR 测试、备份设备原版，不直接修改默认分支或推送到用户设备。
